# 📋 Interactive Kanban Task Management Board

A dynamic task-management board designed to organize workflows, structure project phases, and track task progress in real time.

![License](https://img.shields.io/badge/license-MIT-blue.svg)
![Tech Stack](https://img.shields.io/badge/tech-HTML5%20%7C%20CSS3%20%7C%20JS%20ES6-yellow)

---

## 🌟 Key Features

- Multi-Column Workflow Setup: Categorizes tasks cleanly into progress stages (*To-Do*, *In Progress*, *Completed*).
- Interactive State Updates: Transfer tasks between columns effortlessly to reflect current progress status.
- Persistent State Management: Automatically syncs board status with browser localStorage to retain data on refresh.
- Dynamic Task Creation & Removal: Create custom task cards, edit descriptions, and purge finished items safely.
- Modern Responsive Design: Clean UI architecture styled with dynamic feedback states for optimal user experience.

---

## 🛠️ Tech Stack

- HTML5: Modular UI containers and form inputs.
- CSS3: Custom board styling, dynamic column layouts, visual state cues.
- JavaScript (ES6): Object state management, array iterations (.map(), .filter()), DOM event routing, localStorage integration.
